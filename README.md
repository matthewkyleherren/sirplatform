# p448-poc

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.3.5. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.

> This repository is Bun-first: always prefer `bun`/`bunx` commands and Bun’s native APIs over Node.js equivalents or npm/yarn tooling.
